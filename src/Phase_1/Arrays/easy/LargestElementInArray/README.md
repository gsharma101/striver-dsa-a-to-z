# Largest Element in an Array

## Problem Statement

Given an array, find the largest element present in the array.

---

## Examples

### Example 1

```text
Input:
arr[] = {2, 5, 1, 3, 0}

Output:
5
```

### Explanation

`5` is the largest element in the array.

---

### Example 2

```text
Input:
arr[] = {8, 10, 5, 7, 9}

Output:
10
```

### Explanation

`10` is the largest element in the array.
